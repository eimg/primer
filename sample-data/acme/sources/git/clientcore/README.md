# ClientCore

Synthetic Acme CRM repository used only as Primer knowledge-source data.

ClientCore manages customer accounts, contacts, deals, and activities. This fixture is intentionally small and is not an active product implementation.

## Useful identifiers

- `CC_IMPORT_017` — explicitly supplied owner email is not an active tenant user.
- `activityDedupeKey` — stable key for imported activities.
- `archiveAccount` — hides an account from default search without deleting history.
