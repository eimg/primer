# TalentFlow

Synthetic Acme job-portal repository used only as Primer knowledge-source data.

TalentFlow manages employer accounts, jobs, candidates, applications, interviews, and notifications. This fixture is intentionally small and is not an active product implementation.

## Useful identifiers

- `retryNotification` — retries mail delivery while preserving an idempotency key.
- `APPLICATION_WITHDRAWN_TERMINAL` — employer transition rejection for withdrawn applications.
- `RESUME_URL_TTL_SECONDS` — signed resume URL lifetime.
