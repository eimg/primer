# TalentFlow application lifecycle

## Withdrawn applications

`withdrawn` is a terminal candidate-controlled state. Employers cannot reopen a withdrawn application.

If the candidate wants to return, they must submit a new application while the job accepts applications. The original remains in the employer audit view and is never rewritten as active.

## Employer rejection

`rejected` is an employer decision. Support may correct an accidental rejection through the audited administrative process; this exception does not apply to candidate withdrawal.
